## Проверка распознавания

`tests/handwriting.json` содержит **вручную заданные координаты**, независимо от KanjiVG, а не записи физического почерка пользователя. Эти штрихи также вводились в Canvas потоком мыши через Playwright. Это полезная проверка алгоритма и связки Canvas → Worker → проверка ответа, но не оценка точности для реального почерка.

| Ввод | Результат |
|---|---|
| 山 | 山 |
| 人 | 人 |
| 川 | 川 |
| 土 | 土 |
| 士 | 士 |
| 日 | 日 |
| Пусто | неопределённый результат / просьба заполнить поля без засчитывания попытки |
| 山 без последнего штриха | неопределённый результат |
| Каракули | неопределённый результат |

Похожие 土/士 различаются в данном небольшом наборе. В приложении правильный распознанный N5-ответ проверен через ввод указателем. Неправильный ответ проверен отдельно через клавиатуру. Автоматическая проверка связывает результат независимого распознавания с точным ответом, а не принимает ожидаемую траекторию как доказательство правильности.

Измерения времени в `recognition-results.json` относятся к среде выполнения, не к реальному iPhone. Порог качества и полнота штрихов ограничивают метод. Нет тестового покрытия реальным рукописным вводом всех сложных слов N4–N1. Проверку порядка черт приложение не заявляет.

## Не проверено / ограничения

- Физический iPhone, Safari/iOS, Apple Pencil и другие аппаратные стилусы: проверялись эмуляция размеров, DPR и события touch в Chromium. Это не аппаратная сертификация.
- Свободный человеческий почерк и сложные кандзи всех уровней, вариативность начертаний; нет основания обещать высокую общую точность.
- Реальная игра MoriGarden: проверены README и код, не запущена Windows-сборка.
- Холодный офлайн-запуск: не заявлен, service worker отсутствует. Уже загруженное приложение не отправляет штрихи в сеть.
- Фактический новый GitHub Pages deployment: не выполнялся по прямому запрету владельца. Совместимость проверена локальной статической раздачей, реальными каталогами, абсолютными путями и отсутствием backend-зависимости.
- Автоматический axe не заменяет полный аудит скринридером и ручную проверку всех критериев WCAG.
- Доступность внешних сайтов не гарантируется. Tanos был недоступен из среды, поэтому словарь проверен по открытому GitHub-зеркалу с attribution и точным commit.

Повторный запуск: `npm ci`, отдельно поднять локальный сервер, затем `npm test`. Конфигурация не запускает деплой.
