## Распознавание: регрессия и пределы

Исходники `recognizer.js` и `worker.js` совпадают с опубликованной версией 1. Повторно проверены независимо заданные координатные образцы 山, 人, 川, 土, 士, 日: все возвращают ожидаемый знак. 土/士 различаются в данном наборе. Пусто, неполная 山 и каракули дают неопределённый результат. Связка Canvas → Worker → Correct проверена указателем мыши и потоком touch для 山.

**Это не записи свободного почерка реальных людей.** Фикстуры заданы вручную координатами и воспроизводятся через браузерные события. Нельзя на этой основе заявлять высокую общую точность, проверку Apple Pencil или распознавание всех сложных знаков. Проверка настоящего почерка и физических устройств остаётся ограничением работы. Не используется заведомый ответ для выбора кандидата распознавателем. 書き順 не оценивается.

## Lighthouse — мобильный профиль, локальный сервер

| Страница | Performance | Accessibility | Best Practices | SEO |
|---|---:|---:|---:|---:|
| Главная | 94 | 100 | 100 | 100 |
| Kanji Recall (страница проекта) | 99 | 100 | 100 | 100 |

Сырые отчёты: `artifacts/v2/lighthouse-home.json`, `lighthouse-kanji.json`. Это реальные отдельные прогоны, не гарантированные production-значения и не оценка всех страниц. Локальный Python-сервер не имитирует CDN GitHub Pages. Lighthouse страницы проекта не измеряет точность и время распознавания после начала занятия.

При первом прогоне приложения Performance был 77: полный каталог и распознаватель загружались сразу. Реальное изменение поведения — малый первоначальный набор, каталог по запросу и распознавание при начале рукописного занятия — сократило LCP примерно с 6.3s до 1.7s в проверенном локальном мобильном профиле. Проверки не отключались, условия распознавателя не подменялись; задержка загрузки теперь честно видна в тренировке. Оставшиеся рекомендации включают блокирующие CSS и серверные cache/compression headers; GitHub Pages управляет ими самостоятельно.

## Повторение

1. `npm ci`.
2. Отдельно `python3 -m http.server 8000`.
3. `npm test`.
4. Дополнительная проверка Lighthouse: `CHROME_PATH=/usr/bin/chromium npx lighthouse http://localhost:8000/ --chrome-flags='--headless --no-sandbox' --output=json --output-path=/tmp/lighthouse.json`.

Не проверены: физические Safari/iOS/Pencil, полноценная работа скринридером, корпус настоящего почерка, полноценный холодный офлайн-запуск и новая production-публикация GitHub Pages. Не утверждается, что они прошли проверку.
