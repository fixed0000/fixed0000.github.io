# MoriGarden: проверка перед галереей

Проверен реальный репозиторий https://github.com/fixed0000/MoriGarden . Локальный HEAD и удалённый main: `ad4523d1529c9b45bbfbc8c7162925e63cb51fa5`.

- Godot.NET.Sdk 4.5.1, C#, .NET 8; собственные скрипты поведения, ухода, движения, окружения и JSON-сохранений.
- README и публичные коммиты от 11.11.2026 подтверждают Chao, сады, предметы, поведение, движение/камеру и сохранения. Страница сохраняет реализованные механики, добавляет краткую историю по коммитам и явно не придумывает планы.
- `Assets/baby-chao.glb` и `Assets/player-city.glb` содержат только generator «Khronos glTF Blender I/O v5.2.41» и glTF version 2.0. Это не сведения об авторе и не лицензия.
- В README, рядом с Assets и в проверенных метаданных нет источника или лицензии, разрешающей публикацию модели Chao и её изображений. Сообщение владельца прямо указывает на стороннюю модель, близкую к SEGA. Бесплатность не считается разрешением.
- Код игры не изменялся. Для проверки среды использована отдельная копия в scratch, не исходный checkout. Первая попытка со стандартным Godot 4.6.3 без .NET не смогла загрузить C#-сцену.
- Затем во временный каталог установлены официальный .NET SDK 8.0.428 и Godot 4.5.1 Mono. `dotnet build Mori.csproj` завершился успешно: 0 warning, 0 error. Импорт ресурсов Godot .NET прошёл успешно.
- `Godot ... --headless --path <scratch copy> --quit-after 180` завершился с кодом 0; журнал содержит заголовок Godot и не содержит ошибок. Это ограниченная проверка запуска/симуляции без визуального рендера, управления игроком и проверки каждой механики.
- Скриншоты не созданы и не опубликованы; сторонние кадры Sonic и изображения, сгенерированные AI, не использованы. Галерея из 3–5 кадров отложена до подтверждения происхождения/условий материала и визуальной проверки. Headless-запуск не выдаётся за снимок работающего интерфейса.

Конкретный следующий шаг: найти исходную страницу загрузки GLB и её лицензию; при отсутствии разрешения заменить модель оригинальной в отдельной задаче по игре. Только после этого получить реальные кадры сада, существ, взаимодействия и интерфейса и подготовить WebP/PNG-галерею. Замена модели не выполнялась, так как репозиторий MoriGarden исключён из области изменений.

Японский и английский дисклеймеры из задания размещены без заявления об одобрении SEGA. Отдельная страница игры и ссылка на исходный код работают; кнопки Play нет.
