# Portfolio 2.0 — реализация для ревью

База: опубликованный `main`, `5e763cfc91bcaff5a900f35b2c011c08bd6b4714`. Продолжение существующего статического сайта, без замены фреймворком. Рабочая ветка: `portfolio-2`. Production в ходе этой доработки не изменяется.

## Реализовано

- Kanji Recall: ровно один кандзи, один Canvas; чтение + английское словарное значение + число черт. 68 небольших проверяемых заданий. Подсказка не содержит ответ; эталон не виден до проверки или явного показа ответа.
- SVG KanjiVG в том же поле и координатах 109×109, opacity 0.25; пользовательские линии сохраняются. Эталон можно отключить, свои линии — скрыть. При новой попытке и следующем задании эталон скрывается.
- Порядок черт из оригинального SVG: Play/Pause/Restart, скорость 0.5–3×, выделение текущей черты, счётчик и итоговая полная форма. Это демонстрация, не оценка последовательности пользователя. Анимация начинается только по явной команде, её можно остановить.
- Крупные Correct/Incorrect/Unrecognized, разные акценты; неопределённое распознавание не увеличивает число ошибок.
- Practice Mode с `100dvh`, safe-area, отдельной панелью записей и настроек, центральным Canvas, выходом и Escape. Фоновая страница скрыта и inert. При 390×664 после ответа: весь режим помещается на экран, Canvas 230 CSS px; на больших экранах поле увеличивается. Очень низкие/горизонтальные экраны могут требовать прокрутки.
- JLPT N5–N1 и независимая классификация 漢検. Для 10–5級 есть малые наборы новых знаков соответствующего школьного года; это не полный экзаменационный syllabus. 4級 и выше явно «準備中». JLPT не пересчитывается в 漢検.
- Избранное, повторение ошибок, случайный порядок, ежедневная задача, экзамен с отложенной обратной связью, записи по уровням, история, сброс с подтверждением, экспорт/импорт JSON, собственные поддерживаемые кандзи, толщина кисти и тёмная тема только тренажёра.
- Сохранён прежний распознаватель и Web Worker. Исходники `recognizer.js` и `worker.js` не менялись.
- Прогресс v2 хранится отдельно; v1 мигрирует без удаления исходного ключа. Многосимвольные результаты архивируются, а не ошибочно распределяются по отдельным кандзи. Старый архив входит в экспорт. Нечитаемая запись не перезаписывается молча.
- Interactive Minimal: прежняя синяя палитра, выразительный hero, две CTA, компактная горизонтальная мобильная навигация, карточки с технологией/статусом, движение секций и hover, focus, reduced motion. Текст в секциях остаётся непрозрачным во время движения.
- Две завершённые исследовательские работы сохранены; на главной короткие названия, на внутренних страницах полные. Новых выводов, выборки или статистики не добавлено.
- Четыре рабочих принципа добавлены по формулировкам нового задания. Интерес к языку связан с исследованиями и Kanji Recall, к играм — с MoriGarden.
- About This Website на двух языках, только ссылка в footer; AI-assisted Development с предоставленным владельцем текстом и уточнением о пределах проверок.
- Breadcrumbs, Open Graph и social preview из реального сайта, единый 404, canonical/hreflang/sitemap.

## Архитектура

22 статические страницы (11 JA + 11 EN); 6 основных вкладок не меняются. `tools/build-site.py` сохраняет прежние факты и оболочку; `tools/enhance-site.py` применяет общие компоненты Portfolio 2. Блоки приложения генерируются `tools/build-app-markup.py` в обеих версиях. Production не требует сборки — HTML уже подготовлен.

Kanji Recall разделён на `app.js` (состояния и сценарии), `canvas.js` (ввод), `reference.js` (SVG/анимация), `store.js` (валидация/миграция/записи), прежние worker/recognizer. Начальная загрузка использует только малый набор задач. Полный каталог нужен для редких пользовательских знаков; SVG загружается по Unicode-блокам. Данные распознавания загружаются при начале рукописной тренировки, не блокируя остальную страницу.

Runtime-библиотеки не добавлены. Dev-инструменты: Playwright, axe, html-validate, Lighthouse. PNG/WebP — снимки настоящего браузерного приложения, оптимизированные по формату, не нарисованные макеты.

## Важное незавершённое

Галерея MoriGarden **не добавлена**: источник/лицензия внешней модели не подтверждены. Вместо игрового изображения карточка честно объясняет причину. Добавлены оба требуемых дисклеймера; они не трактуются как разрешение. Веб-версия игры не придумана. См. [MORIGARDEN.md](MORIGARDEN.md).

Распознавание остаётся ограниченным сопоставлением формы KanjiVG. Проверены координатные образцы и настоящий поток событий мыши/touch через браузерную автоматизацию; это не физические записи произвольного человеческого почерка. Физический iPhone, Safari, Apple Pencil и точность на всех 68 сложных знаках не проверены. Не заявляется универсальная точность или оценка 書き順.
