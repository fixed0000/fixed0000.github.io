# Исходное состояние и проверка источников

Проверка выполнена 12.11.2026 до изменения сайта. Репозиторий клонирован с GitHub; исходная ветка `main`, commit `bca2cf19c28cd41f1511ea425d0d7aa772676d60`. Рабочее дерево было чистым. Локальная ветка `baseline-before-refresh` сохраняет исходное состояние, SHA-256 файлов — `baseline-files.json`. Работа выполняется в `portfolio-refresh`, без push и публикации.

## Действующие страницы

`/`, `/experience/`, `/skills/`, `/education/`, `/research/`, `/contact/` и их эквиваленты `/en/`. Все они использовали `portfolio.css`, без клиентского JavaScript. Данные и навигация — в HTML. Японский язык открывался по умолчанию; языковые ссылки сохраняли раздел. Синие оттенки, светлый фон и типографическая структура сохранены.

## Старые URL и сохранённые файлы

- `playground.html` уже перенаправлял на `/research/`. Это не рабочая игра. `js/game-logic.js` — незавершённый старый прототип с отсутствующими функциями и старой загрузкой переводов; действующий HTML его не подключал. Не используется для MoriGarden и не удалён.
- `experience.html` → `/experience/`; `services.html` → `/contact/`.
- `education.html` → `/education/`, а `#achievements-academic` → `/research/#thesis`.
- `trash.html`, `under-construction.html` → `/`.
- `css/main.css` импортирует старые модульные стили. `js/script.js` — старый переводчик с русским fallback, темами и каруселями; `sakura-animation.js` — старые лепестки. Эти файлы не подключены действующими страницами и сохранены.
- `images/` содержит сертификаты, документы, фотографии, игровую иллюстрацию и декоративные материалы прежнего сайта. Никакие изображения не удалены; личные документы не добавлены в новые блоки.
- `go-server/server.go` — обычный локальный HTTP file server с `-p` и `-d`. Это не сервер распознавания и не production backend. Сохранён.
- `prepros.config` — конфигурация прежней обработки CSS. Сохранена.
- `.nojekyll` уже присутствовал. GitHub Pages обслуживает реальные `index.html` в каталогах; SPA fallback не нужен. Новые URL следуют той же архитектуре. Workflow для автоматического деплоя не добавлен.

Старый manifest ссылался на отсутствующие изображения `images/icons/*` и представлял владельца как Web Developer; исправлен с использованием существующей иконки и её фактического размера 136×120.

Оба PDF присутствовали, но действующие HTML не содержали ссылок на них. Добавлены ссылки в Contact. PDF не изменялись. Японский PDF датирован 24.07.2025, поэтому указан как существующий документ, который может быть устаревшим. В нём Fruitbat Factory начинается в июле 2023, на сайте — в июне: требуется уточнение, сайт пока сохраняет собственные прежние даты.

- Работа о «семье»: старые `js/translations/ja.json` и `ru.json` содержат название и 2024 год; сопоставление двух языковых групп, анкетирование и статус завершённой работы дополнительно указаны владельцем в задаче. Упоминания разных конференций и шаблонных публикаций не перенесены.
- Работа о «物語»: действующий `/research/` и `/en/research/` подтверждают выпускную работу 2025, сопоставление оригинала и перевода. Развёрнутое название восстановлено из `educationPage.achievements.thesisTheme` в прежних переводах. Формальная запись названия требует финального сравнения с дипломом.
- Старые заявления об NLP и собственном аналитическом коде не перенесены: подтверждающего кода/материалов нет.
- Исследовательский план «日本語の依頼応答における断りの予測» в материалах не найден. Не опубликован ни как завершённая работа, ни как подтверждённый план. Университетская принадлежность не добавлена.
