# Lidiia Borodina — Editorial Portfolio

Статический JA/EN-портфолио для GitHub Pages. Основной язык — японский. Краткое описание профессионального опыта предшествует личным проектам; исследования имеют отдельный академический формат.

## Просмотр и сборка

Готовые HTML находятся в корне и работают без сборки на стороне хостинга. Для локального HTTP-предпросмотра с корректной страницей 404:

    python -X utf8 tools/serve.py

Адрес: http://localhost:8000/. HTTP необходим для JSON, ES modules и Worker тренажёра.

Изменение источников:

    npm ci
    npm run build
    npm test
    npm run test:site

Тестам нужен сервер на порту 8000. Укажите CHROME_PATH, если Chrome находится не по стандартному Windows-пути. Существующие тесты тренажёра также поддерживают /usr/bin/chromium. Сборке нужен Python 3.12 или новее; production-сайт не имеет Python- или npm-зависимостей.

## Источники и архитектура

- content/site.json — профессиональные факты, страницы, JA/EN, обязанности, проекты, навигация, переводы интерфейса и SEO-тексты. Каждая запись хранит обе локали рядом. Фрагменты прежних страниц исследований и лицензированной страницы MoriGarden сохранены в этом источнике.
- src/components.py — секции, ссылки, проекты, исследования, текстовые блоки, хронология и квалификации.
- src/build.py — маршруты, общая оболочка, локализация, SEO, sitemap, совместимые старые URL и 404. Он не считывает факты из готового HTML и не выполняет постобработку страниц.
- tools/build-site.py — стабильная точка входа. tools/build-app-markup.py остаётся отдельным источником разметки существующего приложения; npm run build выполняет оба шага.
- css/site.css — единая система стилей портфолио: токены, типографика, сетка, компоненты и адаптация. Прежние portfolio.css и css/interactive.css удалены.
- css/kanji-compat.css — базовые элементы только существующего тренажёра. css/kanji-app.css и js/kanji/ сохранены без изменения механик, нормализации, порогов, хранилища и Worker.
- js/site.js — раскрытие мобильного меню, Escape/focus и поддержка прежних ссылок, локализация страницы 404. Контент, навигация и содержимое доступны без JS.
- assets/screenshots/previews/ — адаптивные WebP из реальных скриншотов. Текущие полноразмерные кадры галерей сохранены в WebP; ссылки открывают исходный размер.

Выбор небольшого Python-генератора позволяет сохранить текущие URL, root deployment и приложения без миграции в SPA. Astro здесь добавил бы зависимости и отдельный deployment-процесс без необходимой пользы. Сгенерированные HTML хранятся вместе с источниками; не редактируйте их вручную.

## Проверки

npm test сохраняет существующие regression-тесты Kanji Recall. npm run test:site проверяет воспроизводимость сборки, JA/EN, HTML, ссылки, 96 раскладок, axe, клавиатуру, меню, текстовые обязанности, галерею, 200% текст и работу без JavaScript. tests/redesign-build.py фиксирует неизменность механик тренажёра относительно bdb1deb для этой миграции; при последующем намеренном изменении приложения этот baseline нужно пересмотреть.

Артефакты редизайна — artifacts/redesign/. Результаты Lighthouse относятся к локальному Chrome с мобильной эмуляцией; это не production-оценка GitHub Pages и не гарантия доступности на всех физических устройствах.
