## Локальный запуск

Для просмотра достаточно Python 3; установка npm и сборка не требуются:

```sh
cd /workspace/portfolio
python3 -m http.server 8000
```

Открыть http://localhost:8000/ или http://localhost:8000/projects/kanji-recall/ . Нужен HTTP, а не `file://`, для JSON, ES modules и Worker. Альтернатива: `go run go-server/server.go -d . -p 8000`.

## Правки и проверки

```sh
npm ci
npm run build
npm test
```

`npm test` предполагает уже запущенный сервер на порту 8000 и Chromium `/usr/bin/chromium`. В другой ОС укажите локальный executablePath в тестах или настройте установленный Playwright browser. Тесты записывают результаты в `artifacts/v2/`; они не публикуют сайт.

- `tools/build-site.py` — факты, двуязычная оболочка и статические страницы; запускает общую обработку `tools/enhance-site.py`.
- `tools/build-app-markup.py` — исходный генератор JA/EN-разметки приложения. `npm run build` запускает оба генератора.
- `css/interactive.css` и `js/site.js` — общая визуальная доработка поверх сохранённого `portfolio.css`.
- `css/kanji-app.css` — отдельные стили тренажёра и его темы.
- `js/kanji/app.js`, `canvas.js`, `reference.js`, `store.js` — занятия, ввод, SVG/черты, прогресс. Прежние `recognizer.js` и `worker.js` сохранены без изменения. Отдельные `stroke-order.js`, `stroke-order-worker.js` и `stroke-order-ui.js` выполняют экспериментальное сопоставление последовательности и направления, не изменяя результат символа.
- `assets/kanji/tasks.json` — 68 отдельных знаков; `catalog.json` — поддерживаемые знаки для пользовательских наборов; `shapes/` — оригинальные пути SVG по Unicode-блокам. Полный каталог и распознаватель загружаются по необходимости.

Experience/Education по-прежнему сохраняют подтверждённые блоки из соответствующих HTML. Чтобы изменить факты на этих страницах, правьте четыре HTML и запускайте сборку: блоки сохраняются.

Для повторной подготовки данных из исходников:

```sh
python3 tools/data/build-kanji.py /path/to/pinned/kanji.json /path/to/kanjivg
```

Commit источника и лицензии указаны в `assets/kanji/DATA-SOURCES.txt`. Указанные уровни JLPT не официальны. 漢検 не вычисляется из JLPT, а опирается на школьный класс и официальные требования. Наборы 10–5級 неполные; 4級 и выше — Preparing.

Реальные скриншоты локального приложения/сайта: `node tools/capture-v2.cjs`. Затем WebP можно обновить Pillow из полученного PNG. Скриншоты MoriGarden не создаются этим инструментом.

## Прогресс

`kanji-recall-v2` в localStorage содержит статистику по символам, историю, избранное, собственный набор и настройки. При первом запуске старый `kanji-recall-v1` сохраняется и архивируется в v2. Односимвольные результаты переносятся, многосимвольные не распределяются по знакам. Экспорт содержит архив. Импорт и полный сброс требуют подтверждения внутри приложения. Запрет storage оставляет сессионный режим, не блокируя клавиатурную тренировку.

## Ограничения и публикация

Распознавание — экспериментальное сопоставление с KanjiVG, не универсальная нейросеть. Порядок черт получает отдельную экспериментальную оценку; это не официальная проверка 漢検. Физические iPhone/Apple Pencil и свободный человеческий почерк не проверены. Первое открытие без сети не гарантируется. Нет аналитики, трекеров, backend и cookie banner.

Статика рассчитана на корень `fixed0000.github.io`, с каталогами/index.html и `.nojekyll`. Старые URL, изображения, PDF и Go server сохранены. Слияние в `main` запускает публикацию GitHub Pages. По постоянному указанию владельца от 12.11.2026 готовые проверенные изменения публикуются сразу на https://fixed0000.github.io/ без дополнительного запроса. Более поздний явный запрет публикации для конкретной задачи имеет приоритет.

Материалы `docs/BASELINE.md` и прежние отчёты относятся к версии 1 и сохранены как история, а текущий статус описан в `docs/v2/`.
