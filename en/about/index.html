About This Website

The structure, development approach, technologies, and limitations of this portfolio.

Purpose

A personal career portfolio that distinguishes professional experience, academic research, and personal projects. Development is presented as personal project work, separate from professional technical experience.

Structure & Design

A static site with Japanese as the default and equivalent English pages under /en/. Language links preserve the corresponding route. HTML, CSS, and JavaScript support clear hierarchy, spacing, a navy palette, and restrained interaction feedback.

Responsiveness & Accessibility

The site considers responsive layouts, keyboard operation, visible focus, semantic HTML, and reduced-motion preferences. Automated checks do not guarantee complete accessibility; physical-device and assistive-technology testing remain necessary.

Interactive Work

Kanji Recall uses Canvas, Pointer Events, SVG, a Web Worker, and localStorage. Drawings are not sent to an external service; progress stays on the device. No personal analytics or trackers are included.

AI-assisted Development

I use AI-assisted development tools in my personal projects to help organize requirements, explore features, test functionality, and make iterative improvements. I review generated code and suggestions against the intended behavior and practical requirements.

The implementation report records the scope and limitations of checks. This description does not mean every component was written unaided or that the owner personally performed every test.

Limitations & Next Improvements

Handwriting recognition is an experimental shape-matching implementation. Future work includes broader tests with real handwriting, physical iOS devices and styli, screen readers, and additional verified study data. Third-party materials require source and publication-rights checks.
