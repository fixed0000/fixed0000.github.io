Personal project

MoriGarden

A personal 3D game in development about caring for and interacting with virtual creatures.

Overview

MoriGarden is a non-commercial personal 3D game inspired by Chao Garden, focused on caring for creatures and interacting with them in a garden.

Main Features

  • Explore the garden, call creatures, pet them, and feed them
  • Autonomous wandering, swimming, resting, and playing
  • A shop for fruit, seeds, and eggs; trees, fruit, and item handling
  • Multiple save slots and locations including the main garden and Coastal Cove

Technology & Source Code

Godot 4.5.1 .NET · C# · .NET 8

In development for Windows. Source code and launch instructions are available on GitHub.
