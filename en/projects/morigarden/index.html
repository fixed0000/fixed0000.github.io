MoriGarden

A personal 3D game in development about caring for and interacting with virtual creatures.

Overview

A single-player 3D virtual-creature care game inspired by the Chao Garden systems in Sonic Adventure.

Motivation

A personal exploration of creature growth, autonomous behavior, and interaction with the player.

Implemented Features

  • Third-person movement and camera; pick up, place, and throw objects
  • Egg hatching; petting, calling, and feeding creatures
  • Autonomous wandering, swimming, resting, playing, and social interactions
  • Shop for fruit, seeds, and eggs; tree and fruit systems
  • Autosave, 20 save slots, and backup recovery

Technologies

Godot 4.5.1 .NET · C# · .NET 8 · GLB models · separate Python/Tkinter editor

Status & Limitations

In Development. The README and code were inspected; the game itself was not run in this environment. No public release or web build was found. Current launch instructions target Windows; the game is not embedded in this site.

Roadmap

Specific release plans and future features are not confirmed. Development can be followed on GitHub.
