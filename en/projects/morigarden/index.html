Personal project

MoriGarden

A personal 3D game in development about caring for and interacting with virtual creatures.

Overview

A personal 3D creature-care game inspired by Chao Garden, developed as a non-commercial fan project.

Motivation

A personal exploration of creature growth, autonomous behavior, and interaction with the player.

Main Features

MoriGarden is a personal 3D game focused on caring for virtual creatures and observing their life in a garden.

Players can explore the garden, feed creatures, call them, and pet them. The creatures can independently wander, swim, rest, play, and interact with one another.

The game also includes a shop for fruit, seeds, and eggs, tree and fruit mechanics, item handling, and multiple save slots.

Technologies

Godot 4.5.1 .NET · C# · .NET 8 · GLB models · separate Python/Tkinter editor

Status & Limitations

In Development. Current launch instructions target Windows. No public web build has been confirmed, so the game is not embedded in this site.

Roadmap

Specific release plans and future features are not confirmed. Development can be followed on GitHub.
