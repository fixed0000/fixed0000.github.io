# Работа с портфолио

- Язык общения с владельцем — русский. Сайт: японский по умолчанию и полноценная английская версия.
- Сайт статически собирается из content/site.json и src/ в HTML/CSS/JavaScript для GitHub Pages. Проверяйте соответствующие JA/EN-маршруты.
- Постоянная настройка владельца, повторно подтверждённая 18.11.2026 («всегда заливай на гитхаб»): после необходимых проверок публикуйте готовые изменения на GitHub Pages по обычному адресу https://fixed0000.github.io/ без отдельного запроса подтверждения. Публикация идёт из main, корень репозитория. Дождитесь завершения deployment и проверьте живые изменённые страницы.
- Упоминание необходимости подтверждения в шаблоне ранее приложенного задания не отменяет новое прямое разрешение владельца публиковать. Не останавливайтесь после локального коммита: отправьте изменения, дождитесь GitHub Pages и проверьте живой сайт.
- Явная более поздняя инструкция владельца не публиковать конкретные изменения отменяет этот порядок для соответствующей задачи.
- Эта настройка касается только публикации сайта; она не разрешает изменять репозиторий MoriGarden, придумывать профессиональные факты или использовать модель с NoAI как вход генеративного ИИ.
